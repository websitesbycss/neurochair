# Recording event codes (eego annotation keys)

Annotations are added during recording by pressing the number key on ANT's laptop. Cue words are what the subject is told.

| Key | eego default label | Event | Cue given to subject |
|---|---|---|---|
| 2 | left side | blink | say "blink" |
| 3 | wee | hand movement | say "hand" |
| 4 | ewrf | frown | say "frown" |
| 5 | start | smile | say "smile" |
| 6 | click-chess | Instagram reel (distraction in side vision) | show the reel |
| 7 | custom annotation | clap | say "clap" / subject claps |

The default labels in the software don't match the events; use the key number. Annotation keys are meant for labelling, not precise timing, so expect human lag of a fraction of a second.
